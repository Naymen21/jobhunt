Connecting Gmail (for Outreach)

Free, about 5 minutes. jobhunt sends plain-text emails you've approved through Gmail's normal mail server and reads replies to those threads only (read-only). The password never leaves .env.

  1. Go to myaccount.google.com → Security and turn on 2-Step Verification (App Passwords need it).
  2. Open myaccount.google.com/apppasswords, type a name like jobhunt, and press Create.
  3. Copy the 16-character password Google shows (spaces don't matter). You won't see it again.
  4. In {{ platform().env_file }}, add two lines:
    GMAIL_ADDRESS=you@gmail.com
    GMAIL_APP_PASSWORD=abcd efgh ijkl mnop
  5. Optional: GMAIL_DISPLAY_NAME=Your Name so emails show your name.
  6. Restart the site, open Outreach → Gmail connection test, and send yourself a test email.

Gmail's IMAP access is on by default for personal accounts. If replies aren't detected, check Gmail → Settings → Forwarding and POP/IMAP → Enable IMAP. To revoke access anytime, delete the App Password.
