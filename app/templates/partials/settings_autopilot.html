Schedule it (Windows Task Scheduler)

Set up two tasks: the morning run and an afternoon catch-up that finishes AI steps a usage limit stopped. Your computer can be asleep (it wakes up) but not shut down.

  1. Start menu → type Task Scheduler → open it → Create Task… (not "Basic Task").
  2. General: name jobhunt autopilot; choose Run only when user is logged on.
  3. Triggers → New: Daily, 6:30 AM.
  4. Actions → New: Program {{ pf.python }}, arguments scriptsutopilot.py, start in {{ pf.root }}.
  5. Conditions: tick Wake the computer to run this task; untick Start only if on AC power if you want it on battery.
  6. Settings: tick Run task as soon as possible after a scheduled start is missed; "Stop the task if it runs longer than" 3 hours.
  7. Repeat for jobhunt catch-up: Daily 1:30 PM, arguments scriptsutopilot.py --kind catch-up.
  8. Test: right-click the task → Run, then check the log here.

Schedule it ({{ "macOS launchd" if pf.mac else "cron" }})

Two runs a day: the morning run (6:30 AM) and an afternoon catch-up (1:30 PM) that finishes AI steps a usage limit stopped. A run missed while the computer was asleep starts when it wakes.

    {% if pf.mac %}
  1. Open Terminal and run:
    cd "{{ pf.root }}" && ./scripts/schedule_mac.sh
    It adds two jobs to ~/Library/LaunchAgents (it prints exactly what it writes). Nothing else on your Mac changes.
  2. Optional, so the Mac wakes up for the morning run: sudo pmset repeat wakeorpoweron MTWRFSU 06:25:00
  3. Test now: launchctl start com.jobhunt.autopilot, then check the log here.
  4. To remove them later: ./scripts/schedule_mac.sh --remove
    5. {% else %}
  5. Run crontab -e and add:
    30 6 * * * cd "{{ pf.root }}" && {{ pf.python }} scripts/autopilot.py
    30 13 * * * cd "{{ pf.root }}" && {{ pf.python }} scripts/autopilot.py --kind catch-up
    6. {% endif %}
{% endif %}

To keep Claude from ever using paid usage, leave extra usage turned off in your claude.ai settings. The autopilot also refuses to run if an ANTHROPIC_API_KEY exists on this computer.
